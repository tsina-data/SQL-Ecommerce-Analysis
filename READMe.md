📊 E-Commerce Customer & Sales Data Analysis
Welcome to my end-to-end Data Analytics portfolio project! In this repository, I analyze e-commerce customer purchasing behavior, spending tiers, and order trends using SQL, Python (Pandas), and Tableau Public.
🛠️ Tools & Technologies Used
* **SQL:** Joins, Aggregations ('GROUP BY', 'HAVING'), Conditional Logic ('CASE WHEN'), Subqueries, 'UNION', Window Functions ('RANK'), and CTEs ('WITH').
* **Python:** 'Pandas' for data manipulation, filtering, and revenue calculations ('Google Colab').
* **Data Visualization:** 'Tableau Public' for interactive dashboards and visual storytelling.
## 📂 Repository Contents
* 'query.sql' — Core sales aggregation and customer filtering.
* 'advanced_query.sql' — Customer segmentation into Platinum, Gold, and Silver tiers using 'CASE WHEN'.
* 'subquery_practice.sql' — Identifying high-value orders above specific customer benchmarks.
* 'union_practice.sql' — Merging online and in-store customer records without duplicates.
* 'window_functions.sql' — Ranking customers by total spending and order frequency.
*'cte_practice.sql' — Using Common Table Expressions for clean, readable revenue filtering.
*'ecommerce_pandas_analysis.ipynb' — Python script for DataFrame creation, filtering VIP customers, and calculating total/average revenue.
